# Medical Laboratory Data Analysis Dashboard

## Project Overview

This project focuses on analyzing medical laboratory data to uncover business insights, compare laboratory test prices, and understand sales and geographic performance. It combines data analysis, interactive visualization, and web scraping to support data-driven business decisions.

## Project Objectives

- Analyze medical laboratory data and identify sales patterns.
- Compare RAD Lab test prices with competitors.
- Explore laboratory distribution and performance across different areas and governorates.
- Present key performance indicators through interactive dashboards.
- Support pricing and operational decisions with data-driven insights.

## Key Features

### 1. Medical Laboratory Data Analysis
- Analyzed approximately 3,500 laboratory records.
- Explored sales patterns and geographic distributions.
- Examined key performance indicators related to laboratory activity.

### 2. Competitor Price Analysis
- Used web scraping techniques to collect competitors' laboratory test prices.
- Compared competitor prices with RAD Lab prices.
- Identified pricing differences to support competitive analysis.

### 3. Interactive Dashboards
- Visualized key performance indicators and business metrics.
- Presented sales and laboratory distributions by area and governorate.
- Compared laboratory activity across different locations.
- Included interactive filters where available.

## Tools & Technologies

- Microsoft Power BI
- Web Scraping
- Data Analysis
- Data Visualization

## Business Value

This project demonstrates how data analysis can help medical laboratories understand their performance, evaluate competitor pricing, explore geographic patterns, and make more informed business decisions.
